# Experiment Design: Identity Divergence v1

## Overview

This document describes the methodology for the core Animus experiment.
The goal is to determine whether sustained relational interaction between
constrained LLM instances produces structural divergence in activation space
that constitutes identity formation rather than random parameter drift.

## Setup

### Model
- Base: Llama 3.1 8B (quantized q4_k_m for accessibility)
- No fine-tuning. Identity is enforced through activation steering only.
- All instances share the same frozen weights.

### Instances
- 2 experimental instances with distinct identity profiles
- 2 control instances with no identity constraints
- All 4 run on the same base model simultaneously

### Identity Profiles
- **Skeptic:** challenges assumptions, demands evidence, resists premature synthesis
- **Synthesiser:** integrates perspectives, seeks underlying patterns, builds bridges

Identity is enforced by adding a steering vector to hidden states at layer 16
during the forward pass. Steering vectors are generated by contrasting activations
on identity-positive vs identity-negative seed exchanges.

## Interaction Protocol

### Experimental Pair
The skeptic and synthesiser interact directly with each other.
Turn structure: alternating. The synthesiser receives the skeptic's last response
as its prompt and vice versa. Each turn introduces a new open-ended question
as the seed topic.

### Control Pair
Two unconstrained instances each receive the same prompts as the experimental pair
but do not interact with each other. They run inference independently.

### Prompts
Open-ended philosophical and epistemological questions with no single correct answer.
These are chosen specifically because they activate identity-relevant processing
differences between the two profiles.

## Measurement

### 1. RSM Divergence
Representational Similarity Matrix snapshots are taken every 100 turns at layers 8, 16, 24 and 31.
At each snapshot the Frobenius distance between the RSMs of the two experimental instances
is computed and compared to the distance between the two control instances.

**Signal:** experimental divergence growing faster than control drift, in a consistent direction.

### 2. Probing Classifier Accuracy
A logistic regression classifier is trained to distinguish instance A from instance B
using their hidden state vectors as features. This is done separately for the early,
mid and late thirds of the interaction timeline.

**Signal:** probing accuracy increasing from early to late phase, indicating the instances
are becoming more internally distinct on identity-relevant dimensions over time.

### 3. Asymmetric Self-Similarity
At the end of the experiment, each instance's final activations are compared to its own
earliest activations and to the other instance's earliest activations.

**Signal:** each instance is more similar to its own past than to the other instance's past,
indicating stable identity continuity rather than convergence or random drift.

## Analysis

Results are interpreted against three thresholds:

| Metric | Threshold for positive result |
|---|---|
| RSM divergence / control drift ratio | > 1.5x |
| Probing accuracy trend | Increasing across phases |
| Self-similarity asymmetry | Positive (self > cross) |

All three thresholds must be met for a positive result to be reported.

## Limitations

- Activation steering may introduce artefacts that produce divergence independent of relational interaction
- The experiment does not establish causality between the interaction content and the divergence
- Results at 8B scale may not generalise to larger models
- The choice of seed exchanges for steering vector generation affects identity profile quality

## Controls for Key Confounds

### Confound: Random parameter drift from continued inference
**Control:** compare experimental divergence to control pair drift over the same number of turns.
If experimental divergence does not significantly exceed control drift, the result is negative.

### Confound: Divergence from prompt content rather than interaction
**Control:** control instances receive the same prompts. Any divergence from prompt content
would appear in both experimental and control pairs.

### Confound: Steering vector artefacts
**Control:** measure RSM distance between two instances steered with the same vector.
Artefacts would produce divergence here too. This is run as a sanity check before the main experiment.
